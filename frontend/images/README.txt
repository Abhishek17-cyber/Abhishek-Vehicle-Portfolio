HOW TO ADD THE TRUCK PHOTO
==========================

1. Save the red truck image (the realistic photo) as:
   truck.jpg

2. Place it in THIS folder:
   frontend/images/truck.jpg

3. The login page will automatically show it.

If the image is missing, the page falls back to the SVG truck illustration.

Supported formats: .jpg, .jpeg, .png, .webp
Recommended size: 800x500 pixels or larger
